# Chrono — Полный план исправлений

## Проблемы (из исследования)

1. **Виджеты на Android не обновляются** — единственный триггер: системный 15-минутный `updatePeriodMillis`. Нет WorkManager, нет BOOT_COMPLETED, нет push-обновлений из приложения. `getWidgetId()` всегда возвращает `""` — фильтр проекта мёртв.
2. **Дизайн Android отстаёт от десктопа** — FAB не работает, клик по дню календаря не работает, toggle подзадач не работает, удаление в kanban не работает, Gantt — заглушка, lobby join loading фейковый, двойная навигация, ThemeStore не инициализируется, светлая тема сломана.
3. **Заметки не синхронизируются** — десктоп: `localStorage`, Android: `SharedPreferences`. Ни одна платформа не пишет в Firebase. Нет поля `notes` в `Snapshot`.
4. **Дублирование проекта при join** — Android `joinProject()` пишет новый entry в `users/{uid}/projects/{pid}`, а десктоп — нет. При открытии десктопа проект появляется дважды.

## Верификация

1. **Notes Sync**: создать заметку на десктопе → проверить появление на Android (и наоборот). Проверить realtime обновление.
2. **Duplicate Project**: присоединиться к проекту на Android → открыть десктоп → должен быть один проект.
3. **Widgets**: создать задачу в приложении → виджет обновится в течение секунд. Перезагрузить телефон → виджет показывает данные.
4. **UI/UX**: проверить каждый исправленный элемент вручную на эмуляторе/устройстве.
5. **Сборка**: `./gradlew assembleRelease` для Android, `npm run build` для десктопа.
