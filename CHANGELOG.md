# Changelog

## v4.0.0 (14.11.2026)

### Новое
- **Полный переход на Rust** — десктоп-приложение переписано с Electron на Tauri 2. Ядро (парсер быстрого ввода, дерево задач, канбан, экспорт .ics, хеши паролей, OAuth PKCE, локальный кэш) теперь на Rust.
- **Мгновенный запуск и маленький размер** — бинарник 5.6 МБ против ~200 МБ у Electron, памяти и времени старта заметно меньше.
- **Локальный кэш на диске** — снапшот проектов и задач пишется в файл через Rust-процесс, приложение работает офлайн и открывается мгновенно.
- **Авторизация через системный браузер** — Google OAuth с PKCE и loopback-перехватом кода реализован на Rust (порт 53117).

### Улучшения
- Кнопки окна, перетаскивание за шапку, сворачивание/разворачивание работают нативно.
- Сборка установщиков: NSIS для Windows, deb/AppImage/rpm для Linux.

### Замечания
- Android и веб-версия не менялись.
- Старые `electron/` и PPA-скрипты под Electron больше не используются.
